# 🐍 Data Engineer in Python — Lộ trình MIỄN PHÍ

> Mô phỏng track "Data Engineer in Python" của DataCamp (14 khóa + 3 project + code-along), dùng tài nguyên 100% miễn phí.

**Ước tính thời gian:** ~40-45 giờ
**Điều kiện tiên quyết:** Nên hoàn thành lộ trình [Associate Data Engineer in SQL](#) trước (đã làm ở phần trước) — vì track này giả định bạn đã biết SQL cơ bản.
