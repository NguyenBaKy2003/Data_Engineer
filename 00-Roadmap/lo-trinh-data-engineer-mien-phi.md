# 🎓 Associate Data Engineer in SQL — Lộ trình MIỄN PHÍ

> Mô phỏng lại track "Associate Data Engineer in SQL" của DataCamp, nhưng dùng 100% tài nguyên miễn phí. Cấu trúc gồm 9 khóa học + 2 project + 1 skill assessment, giống hệt bản gốc.

**Ước tính thời gian:** ~30-35 giờ (tự học, có thể co giãn)
**Yêu cầu:** Không cần biết code trước, chỉ cần kiên trì

---

## 📘 Khóa 1: Understanding Data Engineering
*Hiểu data engineer làm gì, không cần code*

| Chương | Tài nguyên miễn phí |
|---|---|
| Data Engineering là gì? | [freeCodeCamp – "What is Data Engineering"](https://www.freecodecamp.org/news/) + video YouTube "Data Engineering Explained" (kênh **Seattle Data Guy**, **DataTalksClub**) |
| Lưu trữ dữ liệu | Đọc **"Fundamentals of Data Engineering"** (sách O'Reilly, bản PDF/preview có sẵn nhiều nơi) – chương 1-2 |
| Di chuyển & xử lý dữ liệu (ETL/ELT) | Playlist **"Data Engineering Zoomcamp"** của DataTalksClub (miễn phí, trên GitHub + YouTube) |

✅ Mục tiêu: nắm khái niệm pipeline, ETL/ELT, kho dữ liệu (data warehouse), data lake.

---

## 📘 Khóa 2: Introduction to SQL
*Học tạo và truy vấn database trong ~2 giờ*

- **[SQLBolt](https://sqlbolt.com/)** — bài tập tương tác, học SELECT cơ bản (miễn phí, không cần đăng ký)
- **[W3Schools SQL Tutorial](https://www.w3schools.com/sql/)** — lý thuyết + "Try it Yourself"
- **[Mode SQL Tutorial](https://mode.com/sql-tutorial/)** — giải thích sâu hơn

✅ Thực hành: chạy thử trên **[SQLite Online](https://sqliteonline.com/)** hoặc **[DB Fiddle](https://www.db-fiddle.com/)**

---

## 📘 Khóa 3: Intermediate SQL
*Data Aggregation, Transformation, Filtering, Conditional Operations*

- **[SQLZoo](https://sqlzoo.net/)** — bài tập theo chủ đề, có chấm điểm tự động
- **[HackerRank SQL Track](https://www.hackerrank.com/domains/sql)** — luyện GROUP BY, HAVING, CASE WHEN
- **[Khan Academy – Intro to SQL](https://www.khanacademy.org/computing/computer-programming/sql)**

✅ Thực hành: giải 15-20 bài trên HackerRank (mức Easy → Medium)

---

## 📘 Khóa 4: Joining Data in SQL
*JOIN, UNION, subqueries*

- **[SQLBolt – phần JOIN](https://sqlbolt.com/lesson/select_queries_with_joins)**
- **[LeetCode – Database category](https://leetcode.com/problemset/database/)** (nhiều bài free)
- **[SQLTeaching – Joins](https://www.sqlteaching.com/)**

✅ Project thực hành ngay: xem project bonus bên dưới.
